# Icon index

The skill's icon library: 213 icons from Material Symbols Rounded, exported from the Slide Skill 2.0 Figma file (Icon Library frame 18:782). Each icon is a single-colour 48 × 48 SVG at `assets/icons/<name>.svg`, filled Midnight (#17132F) by default.

- Place an icon with `addIcon(slide, name, x, y, size, color)`, or put it on a tinted tile with `addIconTile(slide, name, x, y, { tint, color })`.
- Pick the icon by matching the slide's content to the keywords below, not by guessing a Material name. The machine-readable copy is `assets/icons/index.json`.
- Only use names from this list. Never use unicode stand-ins or emoji in place of an icon.
